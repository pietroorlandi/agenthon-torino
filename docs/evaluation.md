# Criteri di valutazione e checklist

| Criterio | Cosa fare |
|---|---|
| Innovazione | Un'idea/angolo non banale, anche su un caso d'uso semplice |
| Coerenza con il brief | Rileggere il brief ufficiale prima di ogni decisione; mappare ogni feature a un punto del brief |
| Fattibilità | Scope ridotto, realizzabile e realistico in azienda/marketing |
| Esecuzione | Demo che funziona end-to-end, UI pulita, dati di esempio |
| Pitch finale | Problema → soluzione → demo live → impatto; provarlo almeno 2 volte |

## Checklist finale
- [ ] Demo funzionante da `main` con un solo comando
- [ ] Piano B (video/screenshot) se la demo live fallisce
- [ ] Pitch provato e cronometrato
- [ ] README con istruzioni
- [ ] Nessun segreto nella repo
